# 🎤 AI Interview Coach

An AI-powered interview preparation platform built with **Python, Streamlit, and Google Gemini API**.

AI Interview Coach allows users to upload their resume, select a target role and difficulty level, and practice a personalized interview with AI-generated questions and answer evaluations.

## 🚀 Features

- 📄 Resume upload
- 🤖 AI-generated interview questions
- 🎯 Resume-based personalized questions
- 💼 Multiple target roles
- 📊 Beginner, Intermediate, and Advanced difficulty
- 🎤 Technical, HR, and Mixed interviews
- 📝 AI-powered answer evaluation
- ⭐ Score out of 10 for each answer
- 📈 Interview progress tracking
- 🏆 Final interview dashboard
- 💡 AI-generated strengths and weaknesses
- 🎯 Personalized improvement recommendations
- 🔄 Start a new interview
- 🔐 Environment-variable based API key protection

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- PyPDF
- python-docx
- python-dotenv
